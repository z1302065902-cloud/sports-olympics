# 奥运50关 · 运动大冒险

体育类游戏，50关每关不同体育项目！

## 玩法
- 🏃 田径：跳远、铅球、标枪、铁饼
- 🏊 水上：跳水、游泳
- ⚽ 球类：足球、乒乓球、羽毛球、篮球、高尔夫
- 🥊 格斗：拳击、摔跤、柔道、击剑
- ⛷️ 冰雪：滑雪、滑冰
- 💪 力量：举重
- 🎯 射击：射箭、射击
- 🧗 户外：攀岩、登山、马拉松

## 操作
- 点击/空格：开始游戏
- 点击屏幕：执行动作
